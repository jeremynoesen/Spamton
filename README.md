# Spamton

## About

Spamton is a Discord bot that applies Spamton's typing quirk to messages.

## Purpose

Me and my friends are huge DELTARUNE fans. I created this originally for use in our private server. After other people
expressed interest in this bot, I polished it up so Spamton can become a [[BIG SHOT]]!

## Usage

Right click any message and go to Apps > Spamton > Dealmaker.

## Installation

Click the link in the top of this repository to install Spamton to your server or user.
